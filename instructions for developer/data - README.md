# data/

**Single source of truth** for facts used across the website.
Update a fact here first, then on the pages that show it.
(Later the backend or a CMS can serve these files directly to the front end.)

| File | Contents |
|---|---|
| `company.json` | Name, contact, figures, awards, partners, social links |
| `navigation.json` | Main menu, dropdowns and footer links |
| `programs.json` | School programs and teacher training (hours, prices) |
| `courses.json` | Techno Camps courses by age group |
| `testimonials.json` | Parent and principal quotes |

Fields marked `"TODO"` need confirmation from Technoknowledge.
