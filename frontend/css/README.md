# css/

Load order (each page links these in this order):

1. `variables.css`: colours, fonts, spacing (brand tokens: change the brand here only)
2. `base.css`: reset, typography, links, buttons
3. `layout.css`: containers, grids, sections, header and footer layout
4. `components.css`: cards, tabs, sliders, forms, badges, FAQ
5. `pages/<page>.css`: styles used by one page only
