**Format and size**

| Use | Size (px) | Max file size |
|---|---|---|
| Hero / slider | 1600 × 1100 | 200 KB |
| Section photos | 1200 × 800 | 120 KB |
| Cards / gallery | 800 × 600 | 80 KB |
| Team portraits | 480 × 600 | 60 KB |
| Logos | SVG preferred, or PNG with transparent background | — |

- Save as **WebP** (JPG if needed). Compress with squoosh.app or tinypng.com.
- Name files in lowercase-with-dashes, e.g. `robotics-line-following-robot.webp`.
- Use real photos of Technoknowledge students and teachers, not stock images.
- Get parents' permission before publishing children's photos.
