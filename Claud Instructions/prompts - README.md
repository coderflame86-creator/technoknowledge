# prompts/

Reusable AI prompts and the brand voice used to write and update website content.
Use these so every page sounds like the same company.

| File | Use it for |
|---|---|
| `brand-voice.md` | Tone, words to use and avoid, key facts. Paste into any AI tool before asking for copy |
| `page-content-prompt.md` | Template prompt to write or rewrite a page section |

Content rules: short sentences, benefits first, real facts from `data/`, no invented numbers.
